# Bugfix Workflow

## Objetivo

Corregir un error existente.

## Flujo

1. Planner

   * Analizar el bug.
   * Localizar el módulo afectado.

2. Backend / Frontend / Database

   * Corregir el problema.
   * Limitar los cambios al alcance del bug.

3. Testing

   * Verificar que el error desaparece.
   * Comprobar regresiones.

4. Reviewer

   * Revisar la solución.

5. Documentation

   * Actualizar documentación si cambia el comportamiento.
