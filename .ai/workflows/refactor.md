# Refactor Workflow

## Objetivo

Mejorar la calidad del código sin modificar el comportamiento.

## Flujo

1. Planner

   * Analizar el código.
   * Detectar mejoras.

2. Backend / Frontend / Database

   * Reorganizar el código.
   * Eliminar duplicidades.
   * Mejorar la estructura.

3. Reviewer

   * Verificar que el comportamiento no ha cambiado.

4. Documentation

   * Actualizar documentación si cambia la estructura del módulo.
