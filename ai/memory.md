# AI Memory

## Objetivo

Registrar conocimiento permanente sobre el proyecto.

## Guardar

* Patrones reutilizables.
* Convenciones del proyecto.
* Decisiones arquitectónicas importantes.
* Soluciones a problemas recurrentes.

## No guardar

* Tareas temporales.
* Estado de una sesión.
* Bugs ya solucionados.
* Información duplicada.

## Principios

* Mantener la información breve.
* Eliminar contenido obsoleto.
* Evitar duplicidades con la documentación principal.
