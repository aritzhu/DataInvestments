# Portfolio

## Objetivo

Permitir al usuario gestionar una cartera de inversión y visualizar el estado de valoración de cada activo.

## Funcionalidades

- Crear cartera.
- Añadir activos.
- Eliminar activos.
- Editar posiciones.
- Calcular valor total.
- Calcular rentabilidad.

## Mostrar

- Precio actual.
- Valor intrínseco.
- Fair Value medio.
- Fair Value recomendado.
- Estado de valoración.
- Rentabilidad.
