# Wallet

## Objetivo

Permitir al usuario gestionar una o varias carteras de inversión.

## Funcionalidades

- Crear una cartera.
- Editar una cartera.
- Eliminar una cartera.
- Añadir posiciones.
- Eliminar posiciones.
- Actualizar posiciones.

## Información mostrada

### Cartera

- Valor total.
- Coste total.
- Rentabilidad.
- Fair Value medio.
- Fair Value recomendado.
- Estado de valoración.

### Posición

- Empresa.
- Ticker.
- Número de acciones.
- Precio medio.
- Precio actual.
- Valor actual.
- Fair Value.
- Margen de seguridad.
- Estado de valoración.

## Dependencias

- Company
- Valuation
- Ratios
